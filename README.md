# サロン経営課題診断アプリ

エステティック通信公式LINEの友だち獲得キャンペーン用の診断コンテンツ（[Chat21統合ランキング](../01_DeepResearchレポート/プレゼントキャンペーン統合ランキング_20260818.html) Sランク1位施策）。

8問の質問に答えると、「新規集客／リピート／利益率／業務効率」の4軸レーダーチャートと、いちばん伸びしろのある領域（診断タイプ）を表示する。外部ライブラリ・サーバー不要の静的サイトで、GitHub Pagesでそのまま公開できる。

## ファイル構成

```
サロン経営課題診断アプリ/
├── index.html          画面構造（イントロ／質問／結果の3画面）
├── style.css            デザイン（ライト/ダーク両対応）
├── script.js             診断ロジック・レーダーチャート描画・ログ送信
├── apps-script/
│   └── Code.gs           回答ログ受信用スクリプト（任意・Google Apps Script）
└── README.md             このファイル
```

## 公開前に設定する項目（script.js 冒頭 `CONFIG`）

| 項目 | 内容 |
|---|---|
| `LINE_ADD_FRIEND_URL` | LINE公式アカウントの友だち追加リンク。診断タイプが `?shindan_type=A〜D` として付与されるので、LSTEP側で流入経路タグ・診断タイプタグを自動付与できる |
| `LOG_ENDPOINT` | 回答ログ（個人情報なし・スコアのみ）を記録するGoogle Apps Script Web AppのURL。空欄のままでも動作する（ログ機能だけ無効化） |

## 回答ログの取り方（任意・簡易版）

1. 記録用のGoogleスプレッドシートを新規作成
2. 「拡張機能」→「Apps Script」を開き、`apps-script/Code.gs` の内容を貼り付けて保存
3. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」／実行ユーザー「自分」／アクセス「全員」で発行
4. 発行されたURLを `script.js` の `CONFIG.LOG_ENDPOINT` に貼り付けてコミット

送信されるのは `q1`〜`q8` の回答スコア（1〜5）とタイムスタンプのみで、氏名・サロン名等は取得しない。

## 診断ロジック

- 4カテゴリ × 2問 = 8問、各5段階評価
- q7・q8（「追われていませんか」等の困りごと系設問）はスコアを反転して合算
- カテゴリ平均が最も低い（＝課題が最も大きい）軸を「診断タイプ」として提示
- 設問カテゴリの根拠は [Chat21統合ランキング](../01_DeepResearchレポート/プレゼントキャンペーン統合ランキング_20260818.html) の元になった3社（ChatGPT／Gemini／Claude）リサーチで共通して上位に挙がった経営課題（新規集客・リピート・利益率・業務効率）
