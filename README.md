# サロン経営タイプ診断アプリ

エステティック通信公式LINEの友だち獲得キャンペーン用の診断コンテンツ（[Chat21統合ランキング](../01_DeepResearchレポート/プレゼントキャンペーン統合ランキング_20260818.html) Sランク1位施策）。

MBTI（16Personalities）のような「二択カード形式」で8問に答えると、サロン経営スタイルが**16タイプ**のいずれかに診断される。結果はレーダーチャート・軸ごとの割合バーで可視化し、キャラクター（絵文字マスコット）とタイプ名で提示する。外部ライブラリ・サーバー不要の静的サイトで、GitHub Pagesでそのまま公開できる。

**公開URL**: https://msk1004.github.io/estsushindan0818/

## 診断の仕組み（16Personalities方式）

4つの特性軸 × 各2極 = 2⁴ = **16タイプ**。各軸は「良い/悪い」ではなく「経営スタイルの違い」として設計し、ポジティブな性格診断のトーンに寄せている。

| 軸 | 極A | 極B |
|---|---|---|
| 集客スタイル | 🧲 新規開拓型（G） | 🤝 常連育成型（E） |
| 価値提供スタイル | 💎 単価特化型（P） | ⚡ 回転重視型（V） |
| 運営体制スタイル | 🧵 一人型（S） | 🌳 チーム型（T） |
| 意思決定スタイル | 🔮 感覚型（I） | 📐 データ型（D） |

各軸2問・計8問。1問ごとに「Aに近い／どちらも近い／Bに近い」の3択カードで回答し、軸ごとの平均から4文字のタイプコード（例: `GPSI`）を算出。16通りのタイプにはそれぞれマスコット絵文字・タイプ名・キャッチコピーを設定している（`script.js` の `TYPE_META`）。

軸の切り口自体は、[Chat21統合ランキング](../01_DeepResearchレポート/プレゼントキャンペーン統合ランキング_20260818.html) の元になった3社（ChatGPT／Gemini／Claude）リサーチで共通して上位に挙がった経営課題（新規集客・リピート・利益率・業務効率）を性格診断のトーンに再構成したもの。

## 公開前に設定する項目（script.js 冒頭 `CONFIG`）

| 項目 | 内容 |
|---|---|
| `LINE_ADD_FRIEND_URL` | LINE公式アカウントの友だち追加リンク。診断タイプが `?shindan_type=GPSI` 等として付与されるので、LSTEP側で流入経路タグ・診断タイプタグを自動付与できる |
| `LOG_ENDPOINT` | 回答ログ（個人情報なし・回答とタイプのみ）を記録するGoogle Apps Script Web AppのURL。空欄のままでも動作する（ログ機能だけ無効化） |

## 結果の共有・リサーチ活用（Web設計）

- 診断完了時にURLが `?type=GPSI` のように書き換わり、結果画面へブラウザバック・共有ができる
- 「結果をコピーしてシェア」ボタンで、そのタイプの結果URLをクリップボードにコピー可能（SNSシェア・16タイプ全件の目視確認に利用できる）
- 全16タイプのURL例: `index.html?type=GPSI` 〜 `index.html?type=EVTD`（`script.js` の `TYPE_META` 参照）
- ログ送信を有効化すると、8問の回答（A/N/B）・4文字タイプコード・4軸のスコア（%）がスプレッドシートに蓄積され、サロン経営者の傾向分析・メーカー営業への示唆抽出に利用できる

## 回答ログの取り方（任意・簡易版）

1. 記録用のGoogleスプレッドシートを新規作成
2. 「拡張機能」→「Apps Script」を開き、`apps-script/Code.gs` の内容を貼り付けて保存
3. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」／実行ユーザー「自分」／アクセス「全員」で発行
4. 発行されたURLを `script.js` の `CONFIG.LOG_ENDPOINT` に貼り付けてコミット
